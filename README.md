# Foundation Database — SCP HUB rework

Локальный статический сайт для RP-сервера Demetra.

## Что изменено
- единая понятная навигация;
- адаптивная мобильная версия;
- поиск и фильтрация записей;
- карточки вместо пустых разделов;
- отдельное досье Зоны-40 с данными из предоставленного Google Sites;
- единый визуальный стиль в духе публичных SCP-архивов без зависимости от внешних библиотек;
- все данные вынесены в `assets/data.js`, чтобы их было проще редактировать.

## Запуск
Откройте `index.html` через локальный HTTP-сервер. Например:
`python -m http.server 8080`

Изображения для первой версии не обязательны: интерфейс намеренно работает и без них.
